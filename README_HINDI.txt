AS LUDO KING - Android Studio Project

यह Android Studio का शुरुआती WebView project है। इसमें मौजूदा ऑफलाइन Ludo demo शामिल है।

AAB बनाने के लिए:
1. माता-पिता/अभिभावक की मदद से कंप्यूटर पर Android Studio स्थापित करें।
2. इस ZIP को extract करें।
3. Android Studio में इस folder को Open करें।
4. Gradle sync पूरा होने दें और SDK Platform 35 स्थापित करें।
5. Build > Generate Signed Bundle / APK > Android App Bundle चुनें।
6. नया upload key बनाकर सुरक्षित रखें; इसे किसी से साझा न करें।
7. Release AAB को टेस्ट करें।

महत्वपूर्ण:
- यह project अभी सिर्फ offline demo को Android app में wrap करता है।
- असली Google/Mobile login, online multiplayer, room-code server, privacy policy और production testing अभी शामिल नहीं हैं।
- असली पैसे की बाज़ी/कैश गेमिंग सुविधा शामिल नहीं है।
- Play Console पर publish करने के लिए अभिभावक को अपने नाम से Developer account और सभी लागू Google Play requirements पूरी करनी होंगी।
- App signing key/keystore को सुरक्षित रखें और किसी को पासवर्ड न दें।
